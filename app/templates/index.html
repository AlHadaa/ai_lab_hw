             Course Concepts & Architecture Map
          

          

            Designed for Dr. Mohammed Al-Dhobaie's AI Lab Course, covering all 4 core pillars:
          


          

            
            

              

                 1. Linux Commands (أوامر لينكس)
              

              
    
                
  • chmod +x scripts/*.sh (File permissions)
    • 
                
  • curl -X POST http://... (API testing)
    • 
                
  • ps aux | grep python (Process monitoring)
    • 
                
  • mkdir, ls -la, cat, grep (Filesystem & inspect)
    • 
                
  • Executable bash scripts: setup.sh, run.sh, health_check.sh

                 2. Git & GitHub (أوامر Git)
              

              
    
                
  • git init & clean .gitignore
    • 
                
  • Feature branch workflow: git checkout -b feature/...
    • 
                
  • Conventional commits: feat:, docs:, test:
    • 
                
  • Remote repository synchronization: git push -u origin main

  • Public GitHub Repository ready for Dr. Mohammed Al-Dhobaie.

    • 
                
  • Automated Unit Testing with pytest
    • 
                
  • Comprehensive docstrings and modular architecture.
